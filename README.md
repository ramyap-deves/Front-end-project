# 🍔 Food Ordering Website

A simple, responsive, and user-friendly food ordering website built using HTML, CSS, and JavaScript. This project allows users to explore food items, add items to their cart, and proceed through the checkout process.

## 📌 About the Project

The Food Ordering Website is a beginner-friendly frontend development project created to practise web development skills. It provides a simple interface for browsing food items and managing a shopping cart.

## ✨ Features

- 🏠 Home page with an attractive layout
- 🍕 Food menu with food items
- 🛒 Add items to the shopping cart
- ➕ Update item quantities and manage the cart
- 💳 Checkout page
- ✅ Order success page
- 💾 Local storage to maintain cart information
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and interactivity
- **Local Storage** – Saving cart information in the browser

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `Home.html` in your browser, or use the Live Server extension in VS Code.
4. Explore the menu and test the cart and checkout features.
